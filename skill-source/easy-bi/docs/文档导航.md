## 机器可读入口

- `skills/bundle.manifest.json`：Bundle、Skill、命令、兼容范围和工作区逻辑路径；
- `skills/index.json`：Skill 登记；
- `toolkit/config/runtime.schema.json`：Runtime 配置 Schema；
- 两个 Skill 的 `package.json` 与 `npm-shrinkwrap.json`：TypeScript/Node.js 依赖。
