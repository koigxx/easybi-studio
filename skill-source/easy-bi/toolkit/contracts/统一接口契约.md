# Easy BI Runtime 统一接口契约

Runtime 对业务系统仍只提供三个接口：

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/v1/reports` | 查询报表及可选执行方式 |
| GET | `/api/v1/reports/{reportId}/parameters` | 查询前端可见筛选参数 |
| POST | `/api/v1/exports` | 按 `executionMode` 进入同步或异步分支 |

所有 Runtime 业务响应使用 HTTP 200。同步成功返回 xlsx 二进制；其余成功和失败返回 JSON。调用方必须通过 `Content-Type` 区分。

异步分支需要 Runtime 出站调用业务系统的两个接口：

1. 创建任务：生成开始前创建任务中心记录并返回业务任务 ID；
2. 更新任务：成功时更新状态、文件地址和文件元数据，失败时更新失败状态与简要原因。

两个出站接口的最终字段映射等业务系统正式接口文档提供后冻结。当前配置只固定用途、方法、路径和鉴权位置。

这三个接口和同步导出 CLI 由 `skills/create-report-package` 内置的共享 Runtime 一次性提供。具体报表包注册到 `reports/index.json` 后立即可被发现，不在报表目录重复生成 Server、路由或 Excel 代码。
